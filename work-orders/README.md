# Arbeitsaufträge

Dieses Verzeichnis ist die Eingangs- und Ausgangswarteschlange der Auftragsverwaltung `ordermgr`: neue Aufträge liegen in `incoming/`, zurückgegebene Akten in `outgoing/`. Neue Arbeitsaufträge entstehen aus [`template.md`](template.md).

Inhalt, Auftragsarten, Akte und Statusmodell stehen in [Das Pipwerk-Entwicklungsverfahren](../docs/technical/entwicklungsverfahren.md#arbeitsaufträge).
