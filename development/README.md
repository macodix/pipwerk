# Entwicklung

Ablage der Übergabedokumente des Entwicklungsprozesses: Meldungen unter `messages/`, je Vorhaben ein Verzeichnis mit Spezifikation, Arbeitspaketplan, Prüfberichten, Präsentationen und Fragen, darunter je Arbeitspaket Aufträge, Test-, Prüf- und Abnahmeberichte.

Aufbau, Dateinamen und Meldungen stehen im Entwicklungsverfahren (dev-werk, `de/process/development-process.md`, Abschnitt „Übergabedokumente“).
