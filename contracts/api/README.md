# API Contracts

Versioned HTTP API contracts.

- `pipwerk-studio/v1/openapi.json`: the public web API of pipwerk Studio under `/api/v1/`. The file is generated from the application and limited to the paths below `/api/v1/`. How it is generated and what the web API does is described in `docs/technical/pipwerk-studio.md`, section 5.
- `pipwerk-replay/v1/openapi.json`: the web API of pipwerk replay under `/api/v1/` (test accounts, and the data stock of historical price data under `/api/v1/market-data/`: the list of series, the details of a series, the brokers, the import of several files in one process (`multipart/form-data`) with its preview, the instrument data and the completeness; pipwerk replay acquires nothing, so there is no acquisition; later orders add the test runs). The file is generated from the application and limited to the paths below `/api/v1/`; it holds examples of the answers and of the form of the import. The technical endpoint `/api/health` and the internal endpoints below `/api/replay/` (settings language and broker for test runs, revision) are not part of it, like `/api/studio/` of pipwerk Studio. A test compares the file with the application and fails on a deviation. How it is generated and what the web API does is described in `docs/technical/pipwerk-replay.md`, section 5.
