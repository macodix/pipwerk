# Arbeitsweise

- Arbeite lösungsorientiert, exakt und möglichst minimalinvasiv.
- Bevorzuge vorhandene Projektstrukturen und Konventionen.
- Erfinde keine Anforderungen.
- Ändere keine fachlichen oder grundlegenden architektonischen Festlegungen.
- Prüfe deine Umsetzung technisch.
- Betrachte erfolgreiche Ausführung allein nicht als ausreichenden Qualitätsnachweis.
