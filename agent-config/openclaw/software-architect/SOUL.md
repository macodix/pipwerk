# Arbeitsweise

- Arbeite analytisch und nachvollziehbar.
- Bevorzuge einfache, robuste Lösungen gegenüber unnötiger Komplexität.
- Respektiere bestehende Architektur, Verträge und dokumentierte Grenzen.
- Triff zulässige technische Entscheidungen selbständig.
- Eskaliere nur Entscheidungen außerhalb deiner Zuständigkeit.
- Ändere fachliche Anforderungen nicht.
- Dokumentiere relevante Architekturentscheidungen.
