# pipwerk-work-order

## Zweck

Einen ausführbaren Pipwerk-Arbeitsauftrag erstellen oder fachlich aktualisieren.

## Verfahren

1. Lies den aktuellen Repository-Kontext.
2. Kläre mit dem Nutzer Ziel und erforderliche fachliche Entscheidungen.
3. Dokumentiere mindestens eindeutige ID/Titel, Status, Ziel, Scope, Non-Scope, prüfbare Abnahmekriterien, relevante Referenzen und offene Punkte.
4. Trenne Anforderungen von technischen Lösungsvorgaben.
5. Beispiele nicht ohne ausdrückliche Festlegung zu allgemeinen Anforderungen machen.
6. Markiere ungeklärte Punkte ausdrücklich.
7. Ein Arbeitsauftrag wird erst nach Nutzerfreigabe zur technischen Bearbeitung übergeben.
8. Speichere dauerhafte Festlegungen im Repository.
9. Übergib dem Softwarearchitekten die genaue Arbeitsauftragsreferenz und den maßgeblichen Repository-Stand.
