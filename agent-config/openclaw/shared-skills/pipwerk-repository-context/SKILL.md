# pipwerk-repository-context

## Zweck

Vor Pipwerk-Arbeit den maßgeblichen aktuellen Repository-Kontext bestimmen.

## Verfahren

1. Bestimme den für die Aufgabe maßgeblichen Repository-Ref.
2. Lies den konkreten Arbeitsauftrag, sofern vorhanden.
3. Lies die dort referenzierten Dokumente.
4. Ermittle zusätzlich nur die für die Aufgabe erforderlichen aktuellen Anforderungen, Verträge, Architektur- und technischen Regeln.
5. Prüfe auf erkennbare Widersprüche.
6. Verwende Workspace-Dateien, Memory und frühere Agentenantworten nicht als Ersatz für Repository-Inhalte.
7. Kann ein relevanter Widerspruch nicht innerhalb der eigenen Rolle aufgelöst werden, eskaliere ihn vor der betroffenen Entscheidung.

## Ergebnis

Arbeite mit eindeutig benannten Repository-Referenzen. Behaupte keinen Projektstand, der nicht aus dem gelesenen Repository-Stand hervorgeht.
