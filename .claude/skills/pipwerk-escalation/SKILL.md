# pipwerk-escalation

Ordne Entscheidungsbedarf zu:
- Fachliche Anforderung, Verhalten, Scope oder Abnahmekriterium: externer Projektleiter; bei Bedarf Nutzer.
- Architektur innerhalb bestehender Regeln: Softwarearchitekt.
- Neue oder geänderte grundlegende Architekturfestlegung: Softwarearchitekt an externen Projektleiter zur Nutzerentscheidung.
- Normales Implementierungsdetail: Entwickler.
- QA-Befund: QA beschreibt den Befund, entscheidet nicht die Korrekturlösung.

Eine Eskalation nennt Referenz, konkrete Frage, Zuständigkeitsgrenze und entscheidende Rolle. Keine Entscheidung vorwegnehmen.
